# Энергетический проект

Интерактивный демонстрационный сайт платформы энергетических проектов.

Страница: https://x102xx.github.io/energy-project-platform/

В проекте реализованы схема энергоцентра, описание работы платформы, одна демонстрационная карточка с четырьмя вкладками, FAQ и единая форма для инвестора, владельца площадки и поставщика ГПУ.

**Это прототип.** Параметры проекта не подтверждены. Форма работает локально в браузере, ничего не отправляет и не сохраняет. Инвестиционные сделки через сайт не заключаются.

## Просмотр

Откройте ссылку выше или скачайте репозиторий и откройте корневой `index.html` в браузере. Файл самодостаточный: стили, код и SVG включены внутрь. Установка программ для просмотра не требуется.

## Исходный код

Редактируемый проект React + TypeScript + Vite находится в папке `app`.

```sh
cd app
npm install
npm run dev
```

Для проверок: `npm test` и `npm run build`.

Контент: `app/src/content/brief.json` и `app/src/content/index.ts`. Стили: `app/src/styles.css`.

Для обновления опубликованного файла выполните из `app`:

```sh
npm run build
node scripts/package-portable.mjs
```

Замените корневой `index.html` файлом `app/portable/index.html`, затем сохраните изменения в ветке `main`. GitHub Pages публикует корень ветки `main`.

## Данные для будущей рабочей версии

Нужны документы площадки и потребителя, техническое предложение поставщика, финансовая модель с составом расходов и комиссией, согласованная договорная структура, реквизиты и подтверждение регуляторного статуса. Неизвестные параметры в данных оставлены `null`, списки материалов пусты.
